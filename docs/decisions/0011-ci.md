# 0011. Tests run in CI on every pull request

Date: 2026-11-15. Status: accepted.

## Context

Claude writes the code and the pipeline team reviews it. A reviewer should not have to run the suite to know it passes.

## Decision

GitHub Actions runs the full suite on every pull request and on `main`: Linux as the gate, Windows as an advisory job until it has proved stable. The workflow installs from pypi.org by name.

## Consequences

If the pilot is accepted the repo moves to Rodeo's GitHub and the workflow file moves with it.
